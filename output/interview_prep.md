## Concepts To Know/Review
- Go fundamentals: modules, interfaces, error handling, testing packages (`testing`, `testify`), `golangci-lint`  
- Concurrency patterns: goroutines, channels, `sync` primitives, worker pools  
- RESTful API design: versioning, pagination, HATEOAS, authentication best practices  
- Microservices: service discovery, gRPC vs. HTTP, data consistency, circuit breakers  
- Performance profiling: `pprof`, benchmarking, memory/CPU optimization strategies  
- Containerization & orchestration: Dockerfile best practices, Kubernetes manifests, Helm charts  
- Cloud architecture: AWS/GCP services for compute, storage, messaging; IaC (Terraform/CloudFormation)  
- CI/CD pipelines: GitHub Actions, blue/green and canary deployments, rollbacks  
- System design basics: data modeling, cron-job scheduling, high availability, fault tolerance  
- Remote teamwork: asynchronous communication, Agile ceremonies, code review etiquette
